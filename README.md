# Quiz Game

A simple web-based quiz game where users can answer questions, track their score, and see their results on a leaderboard.

## Features
- Multiple choice questions
- Timer for each game
- User registration (registration requires a code)
- Only registered users can add new questions
- Leaderboard with top scores

## Usage
1. Run `server.js` to start the backend server.
2. Open `index.html` in your browser.
3. Play the quiz, enter your name, and check your results.

## Requirements
- Node.js
- Modern web browser

## Project Structure
- `index.html` — Main page
- `script.js` — Game logic
- `server.js` — Backend server
- `app.css` — Styles

---

Registration requires a code (for example: KOD=KPEDU).
Only registered users can add new questions to the quiz.
